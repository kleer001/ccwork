# ccwork copy terms

Audience for the README: a Linux developer who uses Claude Code in a terminal
and has never seen ccwork.

## Domain terms

## Decided - keep and gloss
- hooks: the commands Claude Code runs on events such as a prompt or a finished reply
- badge: "status badge" is the colored dot at a row's right edge; the emoji is the "row icon" (the menu still says Set badge…)
- xembed: the X11 protocol that puts one app's window inside another
- userpromptsubmit: paired with "your prompt"
- mid-turn: say "while Claude works on a prompt"

## Decided - replace
- osc: applied live to open terminals
- osc-based: applied live to open terminals
